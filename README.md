## 💻 Local Setup & Development

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

### Backend (Optional)
```bash
cd backend
pip install -r requirements.txt
python run.py
```
Backend runs on [http://localhost:5000](http://localhost:5000).
